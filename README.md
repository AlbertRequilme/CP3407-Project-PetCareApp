# CP3407-Project-PetCareApp
## User Stories:
### 1. Pet Profile Creation
As a pet owner, I want to create a profile for each of my pets so that I can store their basic information (name, breed, age, photo).
### 2. Schedule feeding times.
As a pet owner, I want to schedule feeding times so that I receive reminders when it’s time to feed my pet.
### 3. Track Pet's Medical History
As a pet owner, I want to log vet appointments and vaccinations so that I can keep track of my pet’s medical history.
### 4. Notification System
As a pet owner, I want to receive notifications for upcoming care tasks (feeding, grooming, vet visits) so that I don’t forget important responsibilities.
### 5. Per-Pet Calendar
As a pet owner, I want to view a calendar of all scheduled tasks so that I can plan my pet’s care in advance.
### 6. Note Taking System Per Pet
As a pet owner, I want to record notes about my pet’s health or behavior so that I can share them with the vet if needed.
### 7. Summary Report for Pet's Care History
As a pet owner, I want to generate a summary report of my pet’s care history so that I can review past activities and medical records.
### 8. Manage Multiple Pets
As a pet owner, I want to manage multiple pets within the same app so that I can keep track of all of them easily.
